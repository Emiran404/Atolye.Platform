# Atolye Platform v4.4.3

Küçük hata düzeltmeleri ve kullanım iyileştirmeleri:

- HTTP/yerel ağ bağlantılarında ilk öğretmen hesabı kurulum penceresi yeniden gösteriliyor.
- SQLite modunda JSON yedek geri yükleme uyumluluğu geliştirildi.
- Eski ve farklı JSON yedek biçimleri desteklendi.
- Debian paketine geliştirme verilerinin dahil edilmesi engellendi.
- Sunucu testlerinin doğru şekilde keşfedilmesi sağlandı.
