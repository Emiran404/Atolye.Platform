# Atolye Platform v4.4.4 Beta

Bu sürüm test amaçlı bir beta sürümüdür.

- Yeni kurulumlar doğrudan SQLite veritabanıyla başlar.
- JSON depolama modu ve manuel veritabanı göç ekranı kaldırıldı.
- Eski JSON verileri başlangıçta otomatik olarak SQLite'a aktarılır.
- JSON yedekler doğrudan SQLite veritabanına geri yüklenir.
- Debian kurulumu ve kontrol paneli SQLite-only yapıya uyarlandı.
