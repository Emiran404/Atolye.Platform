# Atolye Platform v4.4.4 Beta 2

Bu sürüm test amaçlı ikinci beta sürümüdür.

- Yedekleme ve geri yükleme sistemi doğrudan SQLite `.db` biçimine geçirildi.
- Otomatik yedeklere SQLite veritabanı dahil edildi; dosyalı ZIP yedeklerinde `database.db` kullanılıyor.
- Yedekler geri yüklenmeden önce SQLite biçim ve bütünlük kontrolünden geçiriliyor.
- Öğrenci istemcisine güncelleme bildirimi, indirme ilerlemesi ve kullanıcı onaylı kurulum eklendi.
- Öğretmen paneline Stable/Beta masaüstü güncelleme kanalı seçimi eklendi.
- Sunucunun indirdiği istemci güncellemelerinin yerel ağda yayınlanması düzeltildi.
- Öğrenci istemcisi Linux, Windows ve imzalı/notarize edilmiş macOS paketleriyle yayınlanıyor.
- Control Panel Linux, Windows ve imzalı/notarize edilmiş macOS paketleriyle yayınlanıyor.
